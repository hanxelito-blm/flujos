Cátedra de Arquitectura: Los 4 Pilares de POO en el nodo Code

Guía técnica y análisis arquitectónico dictado por el Arquitecto de Software Senior y Profesor de Programación.

Pilar 1 ES2022 Private
Encapsulamiento Robusto

Los estados internos se resguardan mediante campos privados (#) inaccesibles desde el exterior. El acceso se controla mediante getters puros y las colecciones retornan clones congelados con Object.freeze().

class Factura { #lineas; #numero; #proveedor; constructor(datos) { this.#lineas = Object.freeze( datos.lineas.map(l => new LineaFactura(l)) ); } get lineas() { return this.#lineas; } }
Garantía arquitectónica: Ningún nodo o script externo puede corromper el detalle de líneas ni las cantidades de una factura.
Pilar 2 Extends & Super
Herencia Especializada

Reutilización de lógica de cabecera y detalle. Las subclases heredan de Factura delegando la construcción base mediante super(datos) y agregando estado especializado (#motivoExencion, #moneda, #tipoCambio).

class FacturaExtranjera extends Factura { #moneda; #tipoCambio; constructor(datos) { super(datos); this.#moneda = datos.moneda; this.#tipoCambio = datos.tipoCambio; } }
Garantía arquitectónica: Cero duplicación de código en cálculo de líneas, números y metadatos comunes.
Pilar 3 Dynamic Dispatch
Polimorfismo (Sin IF para IVA)

RESTRICCIÓN CUMPLIDA: Queda prohibido usar if (tipo === '...'). El cálculo del IVA y del total se resuelve por sobrescritura de métodos. El runtime de JS despacha al método de la instancia concreta.

// En FacturaNacional: calcularImpuesto() { return this.subtotal() * 0.13; } // En FacturaExenta y FacturaExtranjera: calcularImpuesto() { return 0; } // En FacturaExtranjera: total() { return this.subtotalColones() + this.calcularImpuesto(); }
Garantía arquitectónica: Cumple el principio Open/Closed (OCP). Agregar un nuevo tipo no toca el código de cálculo existente.
Pilar 4 Abstract Class
Abstracción Estricta

Factura define el contrato abstracto pero no puede instanciarse directamente. El constructor evalúa new.target === Factura lanzando TypeError, y calcularImpuesto() lanza Error si no es sobrescrito.

class Factura { constructor(datos) { if (new.target === Factura) { throw new TypeError("Factura es abstracta."); } } calcularImpuesto() { throw new Error("Método abstracto."); } }
Garantía arquitectónica: Impide la existencia de facturas genéricas sin política fiscal definida.
Design Pattern Registry Factory
Fábrica de Facturas (FabricaFacturas)

Implementa un registro tipo → clase en memoria privada. En lugar de un switch/if procedural, la fábrica despacha la instanciación en tiempo constante O(1) y lanza ErrorFactura ante tipos no soportados.

class FabricaFacturas { static #registro = { nacional: FacturaNacional, exenta: FacturaExenta, extranjera: FacturaExtranjera, }; static crear(datos) { const C = FabricaFacturas.#registro[datos?.tipo]; if (!C) throw new ErrorFactura("Tipo no soportado"); return new C(datos); } }
Garantía arquitectónica: Extensible en una sola línea mediante FabricaFacturas.registrar('nuevo', Clase).
Reglas de Negocio Regex & Severidad
ValidadorFactura (Cédula CR & Fechas)

Valida cédula costarricense con /^3-\d{3}-\d{6}$/, campos obligatorios, cantidades/precios > 0. Clasifica los hallazgos en dos severidades:

if (!datos.numero || !regex.test(cedula)) { errores.push(...); // -> estado = 'rechazada' } if (new Date(datos.fecha) > Date.now()) { advertencias.push(...); // -> estado = 'revision' } // Sin observaciones // -> estado = 'aprobada'
Garantía arquitectónica: Desacopla la validación de la instanciación permitiendo reportar dinero en disputa.
